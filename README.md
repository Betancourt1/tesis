# tesis
Tesis de modelación matemática para obtener el grado de licenciado en matemáticas por la UdG

Este repositorio almacena todo lo necesario para la realización de una tesis. A saber, tiene lo siguiente:

* Datos necesarios
* Ficheros .tex que contienen la redacción de la tesis
* Bibliografía 
* Ficheros .py y .ipynb que contienen la parte práctica de la tesis
